## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Ignored local artifacts such as old DMGs, Chrome extension zips, generated Xcode projects, Derived output, and screenshots accumulate in the working tree. They are correctly ignored, but release and submission checks can accidentally rely on stale local files unless scripts build into clean output paths and validate artifact freshness.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Release and packaging scripts clean or isolate their output directories before producing artifacts.
- [ ] #2 Submission docs warn that ignored local artifacts are not authoritative unless regenerated by the current script.
- [ ] #3 A local hygiene command or checklist identifies stale ignored release artifacts.
- [ ] #4 Scripts validate artifact version/freshness against the current Project.swift or manifest version before reporting success.
