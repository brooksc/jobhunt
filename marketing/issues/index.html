Support & Bug Reports

Something not working, or have a question? Here's how to get help. Many answers are already in the help guide and FAQ.

Report on GitHub

Best for bugs and feature requests — it's public, searchable, and tracked. Check existing issues first; someone may have already reported it.

Open a GitHub issue →

Email us

Prefer email, or have something private to share (such as logs or screenshots)? Write to us directly and we'll get back to you.

bug@jobhunt-app.com

What to include

To help us resolve your issue quickly, please include:

  • The app version (find it in Settings → General).
  • Your macOS version.
  • A clear description of what happened and what you expected.
  • Steps to reproduce the problem, if you can.
  • A screenshot if there's a visible error.

Please don't include sensitive personal data (such as API keys or full resume text) in a public GitHub issue — use email for anything private.

Browser extension issues

If captures aren't reaching the app, make sure the JobHunt app is open (it runs the local connection the extension talks to), then reopen the extension popup. See Troubleshooting for more.
